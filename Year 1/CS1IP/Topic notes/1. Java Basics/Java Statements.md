#CS1IP 
- A singular instruction (or line ending with ';') is called a **statement**, and a program runs statements in [[Sequencing|sequence]], top to bottom

- ```System.out.println("Hello world");```
	- This Java statement will print the worlds "Hello world"
	- ```System.out.println```is a [[Methods|method]] (or function)
	- "Hello world" is an argument -> The value passed into the method
	- ';' terminates the statement
