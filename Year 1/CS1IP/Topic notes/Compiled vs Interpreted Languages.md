#CS1IP
### Compiled language
- A language that uses a **compiler** program to turn human-readable source code into binary code a machine can execute 
- Generally faster that interpreted languages
### Interpreted language
- A language that uses an interpreter program to execute source code line by line
- Generally more convenient as there is no separate compilation phase
