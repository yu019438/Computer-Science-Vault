## Conceptual Views
| SE views     | Depends on                                                                           | Provides for                                           |
| ------------ | ------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| Paradigm     | Conceptual philosophy (IP/OOP)                                                       | Guides design and thought process                      |
| Architecture | 4+1 model: logical view, development view, process view, physical view and scenarios | Structures software system                             |
| Framework    | Implements paradigm + architecture                                                   | Enables practical coding and reusability               |
| Methodology  | Waterfall, Agile, DevOps                                                             | Guides software development project execution/delivery |
## Conceptual Views Empowered by AI

| SE views     | Choice                                            | Role                                                                             |
| ------------ | ------------------------------------------------- | -------------------------------------------------------------------------------- |
| Paradigm     | Modelling, testing, refactoring, static analysis  | Approach for problem solving and programming                                     |
| Architecture | ArchiMate, TOGAF UML tools                        | modular services -> Business services, application services, technology services |
| Framework    | React (frontend), Flask (backend), TensorFlow(AI) | Implement architecture, AI logic etc.                                            |
| Methodology  | Agile + DevOps                                    | CI/CD pipelines, gathering requirements, continuous feedback loops               |
