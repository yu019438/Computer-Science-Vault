#CS2SE 
**Changes in user requirements**:
- User needs often evolve during the development process
- Late stage changes can affect scope, increased costs
**Technical responsibility**:
- Meeting deadlines without cutting corners
- Compromises can accumulate over time making code harder to maintain, scale and modify
**Testing and debugging**:
- Ensure testing adapts with system growth in size/complexity
- Manual tests are time consuming -> switching to automated tests requires significant sunk costs + maintenance
**Scalability and performance**:
- Performance can degrade when increasing data -> slower response times etc.
- This can lead to poor scalability, limiting growth
**Time and budget constraints**:
- Developers can be forced to operate under strict deadlines or limited budgets
