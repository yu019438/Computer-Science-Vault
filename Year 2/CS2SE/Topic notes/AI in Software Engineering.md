Types of AI used in software engineering:
- Narrow AI (e.g. code suggestions, often inside of IDE)
- Generative AI (Gemini, claude etc.)
- Autonomous systems (self operating software)
## Impact of AI on Software Engineering
- **Gathering data**: Natural language processing (NLP) to interpret user text from documents/other input
- **Design**: AI tools can be used to suggest the right system architecture based on software use case and client needs
- **Coding**: AI can generate code, or repetitive tasks inside of coding allowing the developer to focus more on decision making than writing code
- **Testing**: Automated tests can be carried out faster with AI, as well as bug prediction, and other security analyses 
- Maintenance: AI can be used for log analysis and anomaly detection; identifying issues and reducing run time
