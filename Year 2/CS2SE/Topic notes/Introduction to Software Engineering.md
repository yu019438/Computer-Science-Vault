## What is Software Engineering
Software engineering is the practice of building/maintaining software systems.  It focusses on:
- Reliability
- Scalability 
- Reusability 
- Extensibility
- And user expectations 
In order to successfully build software systems, software engineers have to go beyond just coding:
- **Planning**: Estimations of costs, user numbers, database size etc.
- **Designing**: System architecture, UI, UX, data modelling
- **Testing**: Bug testing/fixing etc.
- **Deployment**: Packing/release, monitoring in production, rollback and recovery strategies, enhancing performance, security
- **Maintenance**: Continuing to fix bugs after release, monitoring performance, enhancing security
---
>[!Software Engineering vs Software Development]
>- Software Development is the broad, hands-on process of writing code and building working applications
>- Software Engineering is a more rigorous, scientific discipline that applies engineering principles to software architecture, scalability, and long-term maintenance.
>- In short: Developers make software work; engineers make sure it scales, lasts, and stays reliable
