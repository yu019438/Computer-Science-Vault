#CS2PP
Comparison operators are used to compare 2 values against each other, and produces a boolean output:
- **Equal to** (`==`):  compares 2 values and produces `True` when comparing values that match, and `False` for values that don't
- **Not equal to** (`!=`): compares 2 values and produces `True` when comparing values that do not match, and `False` for identical values
- **Greater than** (`>`): Tests whether one value is greater than the other
- **Less than** (<): Tests whether one value is less than the other
- **Greater than or equal to** (`>=`): Tests whether one value is greater than or equal to the other
- **Less than or equal to** (`<=`): Tests whether one value is less than or equal to the other
---
## `==` vs `is`
- `==` is a comparison operator, meaning it compares values: `False == 0` -> `True` and `True == 1` -> `True` 
- `is` is an **identity check**: it asks whether both names point to the exact same object
- `False is 0` -> `False`, because they're equal in value but are different objects (a `bool` and an `int`)
