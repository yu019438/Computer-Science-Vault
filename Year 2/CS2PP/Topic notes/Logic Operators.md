#CS2PP 
Logic Operators, like Comparison Operators, compare 2 values, but, they are used to combine booleans.  The main logic operators are:
- `Not` -> Flips a single Boolean
- `and` -> `True` only if **both** sides are `True`
- `or` -> `True` if **at least one** side is `True`
Logical operators are normally used to combine comparisons: 
```Python 
x = 5 
y = -10 
not (x > 0) # False 
x > 0 and y > 0 # False, y is not > 0 
x > 0 or y > 0 # True, x is > 0
```
