#CS2PP
Python follows standard BIDMAS, so brackets first and multiplication before addition.

## Operators
| Operator | Meaning        | Example (`x = 10`, `y = 6`) |
| -------- | -------------- | --------------------------- |
| `+`      | Addition       | `x + y` -> `16`             |
| `-`      | Subtraction    | `x - y` -> `4`              |
| `*`      | Multiplication | `x * y` -> `60`             |
| `**`     | Exponentiation | `x ** y` -> `1000000`       |
| `/`      | Division       | `x / y` -> `1.666...`       |
| `//`     | Floor division | `x // y` -> `1`             |
| `%`      | Modulus        | `x % y` -> `4`              |

---
## Things to remember
- `/` always returns a `float`, even when it divides evenly: `10 / 5` -> `2.0`
- `//` is floor division: divides and rounds down to a whole number: `10 // 6` -> `1`
- `%` is the remainder: `10 % 6` -> `4`
