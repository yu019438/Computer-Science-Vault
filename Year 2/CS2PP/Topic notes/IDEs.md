#CS2PP 
- An Integrated Development Environment (IDE) is a coding tool that allows you to write/test/debug code in an easier way, using features such as:
	- syntax highlighting
	- bracket-matching
	- auto-completing your code
	- debugging
	- code suggestions
- **Examples**: IDLE, Spyder, PyCharm, eric, Vim, Atom, Jupyter, VS Code, PyDev, Thonny

> [!note] IDE vs Code Editor
> - **Code editor**: primarily for *writing/editing text*, with basic programming conveniences (syntax highlighting, bracket-matching) -> doesn't natively run/debug code (e.g. VS Code by default, Sublime Text, Atom)
> - **IDE**: bundles the editor *together with* built-in tools for the whole workflow -> running, debugging (breakpoints, stepping through code, inspecting variables), and often build tools/project management (e.g. PyCharm, Spyder)
> - The line blurs in practice -> VS Code becomes IDE-like once extensions (Python support, debugger, linter) are installed
