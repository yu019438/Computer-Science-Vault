## Indexing 
- Python uses zero-based indexing
- Using square brackets `[]` individual characters in a string can be accessed (as if the string as an Array)
	- character at any position (`n`) in a string (`s`) be accessed using `s[n]`
- The len() function is used to return the length of a string
	- For string `s` where `x = len(s)`
	- Valid indices range from: $0, 1 ... , x - 1$
